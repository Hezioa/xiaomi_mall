# 小米商城官网前端仿写
纯 HTML + CSS 实现的小米商城首页静态页面仿写，用于前端 CSS 布局与动画效果的实战练习。

## 项目介绍
本项目基于小米商城官网视觉风格进行前端还原，全程使用原生 HTML5 + CSS3 实现，不依赖 JavaScript 框架与第三方 UI 库，重点练习 Flex 布局、CSS 过渡动画、层级定位、边框合并等前端基础技能。

## 技术栈
- **HTML5**：语义化标签搭建页面结构
- **CSS3**：Flex 弹性布局、定位布局、过渡动画、伪类交互
- **样式重置**：自定义 reset.css 统一浏览器默认样式
- **设计规范**：1226px 固定内容宽度，贴合小米官网原版布局

## 项目结构
xiaomi-mall/
├── index.html # 首页主文件
├── css/
│ ├── reset.css # 浏览器样式重置
│ └── xiaomi.css # 页面主样式
└── images/ # 页面图片资源（banner、商品图、图标等）

## 已实现功能
### 导航区域
- 顶部通栏广告位
- 黑色顶部导航栏：二维码悬浮下拉、购物车悬浮面板、分隔符样式
- 白色主导航栏：Logo 位移动画、搜索框聚焦变色、导航项悬浮二级商品菜单

### 轮播区域
- 全屏轮播图背景
- 左侧分类侧边栏：菜单项等高均分、悬浮高亮、右侧商品详情网格面板
- 商品网格：行列均分、单边框合并、图片自适应缩放

### 内容区域
- 广告位模块：左右广告卡片 + 中间米芬入口网格
- 手机商品专区：左侧长广告 + 右侧商品卡片网格、悬浮放大阴影效果
- 家电商品专区：商品卡片悬浮底部评论条滑入效果
- 视频专区：视频卡片 + 播放按钮悬浮变色
- 页脚区域：服务导航、友情链接、联系方式

### 交互细节
- 所有可点击元素悬浮颜色过渡
- 商品卡片悬浮放大 + 阴影立体效果
- 图片底部空白消除、相邻边框合并优化
- 二级菜单、悬浮面板的显隐过渡

## 运行方式
1. 克隆/下载项目到本地
2. 直接双击打开 `index.html` 即可在浏览器中预览
3. 推荐使用 Chrome / Edge 浏览器获得最佳展示效果

## 项目亮点
1. **纯原生实现**：无任何框架依赖，适合前端入门学习参考
2. **布局细节完善**：解决 Flex 均分、边框重叠、图片溢出等常见布局坑点
3. **交互还原度高**：还原官网大部分悬浮动效与视觉细节
4. **样式结构清晰**：按模块划分 CSS 代码，便于阅读与修改
